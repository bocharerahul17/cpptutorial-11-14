The root directory (represented simply by a forward slash /) is the absolute base of the Linux filesystem hierarchy.

Every file and folder on the system stems from / (e.g., /usr, /etc, /home, /var)


Root User (The Superuser)
The root user is the administrative account with unlimited privileges.

Complete Control: Root can access, modify, or delete any file, run any command, stop system services, and manage permissions for all other users.

Bypasses Security: Permission bits (rwx) do not restrict root. If a file is marked read-only, root can still overwrite or delete it.



In Linux, Inter-Process Communication (IPC) refers to the mechanisms provided by the kernel to allow separate processes to share data, synchronize actions, or communicate with one another.

Since every Linux process runs in its own isolated virtual address space, processes cannot directly read or write to another process's memory without kernel assistance.

Shared memory
Shared memory is the fastest form of IPC available in Linux because it maps a region of physical memory directly into the address space of multiple processes.

Synchronization Requirement: Because access is concurrent, shared memory must be combined with synchronization primitives like POSIX semaphores or mutexes to prevent data races.

APIs:

POSIX (Modern): shm_open(), ftruncate(), and mmap().

System V (Legacy): shmget(), shmat(), shmdt().


message_queue
Message queues store discrete, structured messages in a linked list maintained by the kernel.

Packet-Based: Unlike pipes (which stream raw bytes), message queues preserve message boundaries.

Priority Handling: Each message can be assigned a priority number. Receivers can fetch messages in FIFO order or retrieve high-priority messages first.
Asynchronous: Writers can post messages to the queue and exit without waiting for a reader to process them immediately.

APIs:

POSIX: mq_open(), mq_send(), mq_receive().

System V: msgget(), msgsnd(), msgrcv().
